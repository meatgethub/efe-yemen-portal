# بوابة التدريب والتسجيل — EFE-Yemen (عدن)

بوابة عربية فقط (RTL) للبرامج التدريبية: تصفح، تقديم بدون تسجيل مسبق، تحقق برمز لمرة واحدة، متابعة الطلبات، تأكيد التسجيل — plus لوحة طاقم منفصلة بأدوار وصلاحيات.

## الهوية البصرية
- الشعار: الملف الرسمي `public/logo-efe-yemen.png` (مقصوص من `EFE-Yemen Horizontal RGB large.jpg` المرفق من الفريق) ويظهر في ترويسة البوابة.
- الألوان: أحمر EFE الأساسي `#991C1F` (زر/ترويسة)، أزرق `#0096BE` للتركيز والروابط المساعدة، خلفية فاتحة `#FAF7F5`، نص داكن بتباين عالٍ.
- الخط: **Thmanyah Sans** (ملفات `woff2` محلية في `public/fonts/thmanyah/` بأوزان 400/500/700/900 — من مجلد الخطوط المرفق، وتُستخدم وفق ترخيصها). أحجام الخطوط كما هي دون تغيير.
- المرجع العام: https://www.efe.org/network/efe-yemen
- حقائق معتمدة فقط من المرجع: تأسست EFE-Yemen 2008، وربط الشباب بالوظائف عبر شراكات القطاع الخاص وتدريب موجه حسب الطلب. أي أرقام أثر أو برامج معروضة هنا **محتوى تجريبي موسوم** ما لم تعتمدها EFE-Yemen.

## ما يعمل فعلياً vs ما هو تجريبي (موسوم بوضوح)
| الميزة | الحالة |
|---|---|
| تصفح/تصفية البرامج، تفاصيل البرنامج | ✅ يعمل — تخزين دائم في `data/db.json` |
| نموذج التقديم متعدد الخطوات + تحقق خادم + رفع ملفات (5MB) + رقم مرجعي + منع التكرار | ✅ يعمل |
| حفظ المسودات محلياً + إرسال الطلب | ✅ يعمل |
| دخول المتقدمين برمز تحقق (بدون كلمة مرور) ولوحة طلباتي والتسجيل | ✅ يعمل (جلسة موقعة 30 يوماً) |
| لوحة الطاقم: CRUD برامج، نشر/إغلاق/أرشفة، نماذج قابلة للضبط، مراجعة، تعيين مراجعين، درجات وملاحظات داخلية منفصلة، مختصرة/انتظار/قبول جماعي وفردي، تصدير CSV، عدّادات، سجل أنشطة | ✅ يعمل |
| دخول الطاقم بكلمة مرور (scrypt) + جلسة httpOnly + أدوار (مدير/مدير برنامج/مراجع) | ✅ يعمل |
| **رمز التحقق OTP** | ⚠️ **تجريبي موسوم**: يُولَّد ويُتحقق منه فعلياً (تجزئة + انتهاء 10 دقائق + حد معدل)، لكن **يُعرض على الشاشة** بدل SMS/بريد. لا يُعتبر إرسالاً حقيقياً. |
| **الإشعارات (SMS/بريد)** | ⚠️ **تجريبية موسومة**: تُسجَّل في `outbox` داخل قاعدة البيانات وصفحة الإشعارات مع حالة «تجريبي — مسجَّل فقط». لا تُرسَل فعلياً إلا بعد الضبط أدناه. |

## التشغيل
```cmd
npm.cmd install
npm.cmd run seed
npm.cmd run dev
```
ثم افتح http://localhost:3000 (المواعيد بتوقيت عدن Asia/Aden).

حسابات تجريبية (غيّرها فوراً):
- `admin / Admin123!` (مدير)
- `programs / Manager123!` (مدير برنامج)
- `reviewer / Review123!` (مراجع)

## التفعيل الحقيقي للإشعارات (إنتاج)
1. انسخ `.env.example` إلى `.env` واضبط `DEMO_MODE=false` و`SESSION_SECRET` طويلاً عشوائياً.
2. للبريد: اضبط `SMTP_HOST/PORT/USER/PASS/FROM` — ثم في `lib/otp.js` استبدل `pushOutbox` بإرسال Nodemailer (أضف الاعتمادية `nodemailer`).
3. للـSMS: اضبط `TWILIO_SID/TOKEN/FROM` (أو مزود يمني محلي) — وأضف استدعاء Twilio API في `app/api/otp/request/route.js` قبل حفظ الرمز. لا تُعد الرمز في الاستجابة في وضع الإنتاج.
4. غيّر كلمات مرور الطاقم، وفعّل HTTPS، وقيّد مجلد `public/uploads`، وراجع سياسة الخصوصية مع الفريق القانوني.

## رحلة الاختبار الكاملة
1. `/` ابحث وصفِّ (عدن/حضوري/مفتوح) → افتح برنامجاً → «قدّم الآن».
2. أكمل 3 خطوات → اطلب الرمز (انسخ الرمز التجريبي من الشاشة) → تحقق → راجع وأرسل → احفظ الرقم المرجعي.
3. `/dashboard` ادخل بنفس الوسيلة والرمز → تتبع الحالة.
4. `/admin/login` ادخل كمدير → الطلبات → افتح الطلب → سجّل درجة وملاحظة داخلية → أضفه للمختصرة → اقبله مع رسالة.
5. كمتقدم: حدّث `/dashboard` → اقبل المقعد → `/enrollment` أكمل المتطلبات.
6. `/admin/export` نزّل CSV، و`/admin/activity` راجع السجل.

## بنية خفيفة لاتصالات بطيئة
- عرض من الخادم (Server Components) للقوائم والتفاصيل، وJS محدود لخطوات النموذج فقط.
- خط عربي واحد من Google Fonts مع fallback، بدون صور ثقيلة أو حركات.
- تحقق مزدوج (متصفح + خادم)، رسائل خطأ عربية تشرح التصحيح، حالات تحميل ونتائج فارغة ومواعيد منتهية معالجة.
